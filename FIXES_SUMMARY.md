# Исправление проблем с зависанием и закрытием модального окна

## Проблемы, которые были исправлены:

### 1. ✅ Зависание на "Загрузка..." 
**Причина**: Добавленный `key={JSON.stringify(page.content)}` на ExtCard вызывал:
- Перемонтирование ExtCard при каждом изменении контента
- Возможный бесконечный цикл рендеринга
- Сброс состояния модального окна

**Решение**: Полностью убран key prop с ExtCard. Теперь:
- ExtCard не перемонтируется при изменении данных
- Нет бесконечных циклов рендеринга
- Админская страница загружается нормально

### 2. ✅ Модальное окно закрывается после сохранения
**Причина**: Та же - key prop вызывал перемонтирование ExtCard, что сбрасывало состояние showDialog

**Решение**: Без key prop ExtCard сохраняет свое состояние, и модальное окно остается открытым после сохранения изменений

### 3. ✅ Моментальное обновление UI
**Как работает теперь**:
- PhotoSelector имеет useEffect (строки 216-244), который синхронизируется с props
- BoxEditable имеет useEffect (строки 14-31), который синхронизируется с props  
- При изменении page.content в MobX store, observer автоматически передает новые props
- Компоненты обновляют свое локальное состояние через useEffect
- UI обновляется моментально БЕЗ закрытия модального окна

### 4. 🔍 Картинка ThreeBottles

## Технические детали:

### До исправления:
```typescript
<ExtCard
  key={JSON.stringify(page.content)}  // ← Вызывало перемонтирование
  Card={...}
  ExtContent={...}
/>
```

### После исправления:
```typescript
<ExtCard
  // Нет key prop - ExtCard сохраняет состояние
  Card={...}
  ExtContent={...}
/>
```

### Как работает обновление UI теперь:
1. User изменяет данные → onContentChange()
2. PageContentStorage.updatePageContentLocal() → runInAction()
3. MobX обновляет page.content
4. observer в AdminPage замечает изменение
5. Новый pageData передается в HomeEdit/VineryEdit
6. PhotoSelector/BoxEditable получают новые props
7. useEffect в PhotoSelector/BoxEditable синхронизирует локальное состояние
8. UI обновляется БЕЗ перемонтирования ExtCard
9. Модальное окно остается открытым ✅

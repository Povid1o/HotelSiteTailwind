# План стабилизации и развития проекта

Дата сверки: 2026-08-03. План основан на проверке текущей ветки
`codex/stabilize-admin`, исходного макета V4 и независимого аудита.

## Уже сделано

- Редактирование и загрузка контента ограничены авторизованным администратором.
- Регистрация больше не принимает роль из запроса; пароль хешируется с cost 12.
- Загрузка файлов ограничена ролями, расширениями, заявленным MIME и размерами.
- Схема БД больше не синхронизируется и не сидируется при каждом старте.
- Сохранение секций страниц переведено на точечные PATCH-запросы с очередью.
- В V4 выровнены шапка, hero, события, дегустационная плашка и футер.
- Контракт кнопок V4: радиус 8 px; hover — полупрозрачная заливка без исчезновения текста.
- Неверные учётные данные при входе теперь возвращают единый `401`, а ошибки валидации — корректный `400` вместо ложных `500`/`404`.

## Ближайший этап — безопасность и надёжность

| Приоритет | Работа | Основание и результат |
|---|---|---|
| P0 | Ротировать JWT-ключ и пароль PostgreSQL во всех средах | Старые значения могли попасть в историю Git. Потребуется одновременно обновить секреты развёртывания; все текущие сессии админов будут завершены. |
| Выполнено | Ограничить запросы к `/api/user/login` | Добавлен лимит: 10 попыток с IP за 15 минут, стандартные rate-limit заголовки и понятный 429-ответ. |
| Выполнено | Исправить CORS на уровне nginx | Убран `Access-Control-Allow-Origin: *` из nginx; единственная политика CORS теперь в Express. |
| Выполнено | Добавить `helmet` и CSP | Helmet включён для API и медиа; публичная HTML-страница получила CSP в report-only режиме с источниками Яндекс.Карт, шрифтов и TravelLine. Enforce включается после анализа нарушений на боевом домене. |
| Выполнено | Обрабатывать истёкший токен в axios | Единый 401-интерцептор очищает сессию и переводит на `/login`, чтобы сохранения не «падали молча». |
| Выполнено | Жёстко отклонять превышенные загрузки | Включены `abortOnLimit`, 413-ответ и дополнительная проверка `truncated`. |
| Выполнено | Валидировать фактический тип медиа | `file-type` проверяет сигнатуру временного файла до переноса в публичное хранилище. |
| P2 | Перевести с JWT в localStorage на httpOnly cookie + CSRF | Это уменьшит последствия XSS. Требует согласованной переработки login/logout и фронтенд-запросов, поэтому выполняется отдельным этапом после 401/CSP. |
| P2 | Убрать устаревшие `/api/type`, `/api/clase`, `/api/product` | Сначала вывести из употребления `productAPI.tsx`, затем удалить маршруты, модели и миграции. Удалять сейчас нельзя: вызовы в проекте ещё есть. |
| Выполнено | Исправить `.gitignore` для манифестов зависимостей | Убраны исключения для отслеживаемых `package.json` и lock-файла; `node_modules` обеих частей проекта явно игнорируются. |

## Следующий этап — скорость публичного сайта

| Приоритет | Работа | Результат |
|---|---|---|
| Выполнено | Убрать глобальную блокировку приложения | `App.tsx` ждёт только проверку сессии. `RouteDataLoader` подгружает данные по открытому маршруту, а главная рендерится сразу с V4-fallback до прихода карточек. |
| Выполнено | Убрать второй router и добавить guard `/admin` | Один router с `RequireAdmin` исключает полный remount при изменении авторизации и сохраняет состояние интерфейса. |
| Выполнено частично | Оптимизировать изображения | В используемой винодельческой карусели и hero четыре PNG заменены на JPEG качества 80: 6,6 МБ → 1,3 МБ. Загрузки уже имеют лимиты; адаптивные `srcset` и массовая миграция исторических неиспользуемых ассетов — отдельная чистка после утверждения. |
| Выполнено | Сделать прямую раздачу загруженных медиа через Caddy | Общий read-only том с загрузками подключён к Caddy: `/static/dishes`, `pages`, `rooms`, `wines`, `videos`, `fallbacks` раздаются напрямую с годовым immutable-кешем. Служебные `/static/js` и CSS остаются у фронтенда, поэтому React-сборка не перехватывается. |
| Выполнено | Убрать автосохранение на каждый символ | Контент секции обновляется локально сразу, а запрос к API отправляется только через 600 мс после последнего изменения. Устаревшие промежуточные правки не попадают в очередь. |
| Выполнено частично | Ограничить и постранично выдавать API-коллекции | `GET /api/pages` поддерживает точный `path`, безопасные `limit` (до 100), `offset` и стабильный порядок. Каталоги пока малы; их пагинация выполняется вместе с будущей переработкой админского списка. |
| Выполнено | Приостановить фоновые проверки во вкладке не в фокусе | `AdminStatusBadge` отключает 15-секундный ping при скрытой вкладке и возобновляет его только при возврате. |
| P3 | Очистить production-логи | Удалить диагностические `console.log` из клиентских storages/API. |
| Отложено | Переезд CRA на Vite | Полезен для скорости разработки, но не заменяет оптимизацию загрузки и медиа. Выполнять отдельной миграцией после стабилизации функциональности. |

## Порядок выполнения

1. P0 безопасности — требует согласования момента ротации секретов.
2. P1 производительности и админского UX — можно внедрять без изменения публичного контента.
3. P2 защиты медиа и оптимизации изображений — с тестовыми файлами и обратимой миграцией.
4. Архитектурные отложенные работы — отдельными небольшими релизами.

# Заявки на вино

В раскрытой карточке вина и на `/Shop/:id` кнопка «Узнать подробности» открывает форму с email. После успешной передачи письма SMTP-серверу форма показывает подтверждение. Менеджер получает название вина, год, цену, ссылку на карточку и email посетителя. «Ответить» в почтовом клиенте адресует ответ посетителю. Автоматическое письмо посетителю не отправляется.

## Подключение

1. В корневом `.env` задайте `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM` и `PUBLIC_SITE_URL` (полный адрес сайта).
2. Обычно порт 465 используется с `SMTP_SECURE=true`, а 587 — с `SMTP_SECURE=false` и обязательным STARTTLS. Используйте параметры вашего почтового провайдера. `SMTP_PASSWORD` — пароль приложения, если провайдер этого требует. `SMTP_FROM` должен быть разрешён для используемого аккаунта.
3. Выполните `docker compose up -d --build`. Для запуска без Docker добавьте те же переменные в `HotelSiteBackend/.env`.
4. В админке → «Вина» → «Заявки на вино» сохраните **Email для заявок на вино**. Получатель хранится в отдельной таблице `wine_inquiry_settings` и доступен через API только администраторам. Пароль SMTP хранится только в окружении сервера.
5. Отправьте пробную заявку из карточки вина и проверьте получение письма и «Ответить».

Пустой адрес получателя отключает приём заявок. Если отправка не настроена или SMTP-сервер отклонил письмо, форма показывает ошибку и ссылку на контакты. Подтверждение SMTP означает принятие письма к доставке, а не гарантированное попадание во входящие.

API: публичный `POST /api/wine-inquiries` принимает только JSON с `wineId`, `email` и необязательным антиспам-полем `website`. Сервер проверяет наличие активного вина, берёт данные товара из БД и получателя из настроек. Ограничение: 5 попыток на IP за 15 минут (счётчик в памяти процесса). `GET/PUT /api/wine-inquiries/settings` требуют сессию администратора; PUT также требует CSRF-токен.

Таблица настроек создаётся без изменения существующих данных при bootstrap контейнера; также предусмотрена миграция `20261111-wine-inquiry-settings.js`. Backend использует Node.js 22 для совместимости с Nodemailer 10.

Документация отправки: [Nodemailer SMTP](https://nodemailer.com/smtp), [поля письма и Reply-To](https://nodemailer.com/message).

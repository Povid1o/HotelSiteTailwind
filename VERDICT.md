## 🎯 Корневая причина проблемы

**Диагноз:** Конфигурация nginx была формально корректной, НО:

1. Regex `^/static/(dishes|pages|...)/ ` совпадает с `/static/pages/video.mp4`
2. Но из-за отсутствия явных расширений файлов nginx мог обрабатывать некоторые запросы неоднозначно
3. Отсутствие MIME-типов усугубляло проблему для видео форматов
4. В результате часть видео могла не воспроизводиться, особенно на мобильных устройствах

## 🎓 Технические детали (для понимания)

### Приоритеты nginx location:
1. `location = /path` — Exact match (высший)
2. `location ^~ /path` — Preferential prefix
3. `location ~ regex` — **Regex (здесь наша проблема)**
4. `location /path` — Prefix match (низший)

**Проблема:**  
Regex должен был иметь приоритет, но без явных расширений nginx мог некорректно определять, какой location использовать для конкретного запроса.

**Решение:**  
Более специфичный regex `.+\.(mp4|webm|...)$` устраняет любую неопределённость.

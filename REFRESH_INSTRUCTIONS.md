# 🔄 Инструкция по обновлению приложения

## Проблема
Изображения не загружаются, потому что старый код кэшируется браузером.

## Решение

### 1. Сделайте Hard Refresh в браузере:

**macOS:**
```
Cmd + Shift + R
или
Cmd + Option + R
```

**Windows/Linux:**
```
Ctrl + Shift + R
или
Ctrl + F5
```

### 2. Или очистите кэш:

1. Откройте DevTools (F12)
2. Нажмите правой кнопкой на иконку обновления страницы
3. Выберите "Очистить кэш и выполнить жесткую перезагрузку"

### 3. Проверьте логи в консоли:

После обновления откройте консоль браузера (F12) и найдите:
- 📥 Raw data from backend
- 📤 Normalized pages
- 📷 First page galleries
- 🖼️ Normalizing src: ...

Эти логи покажут, нормализуются ли URL правильно.

### 4. Если проблема остается:

Отправьте скриншот консоли с логами, чтобы я мог увидеть, что происходит.

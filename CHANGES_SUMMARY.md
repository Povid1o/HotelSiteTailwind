## Как проверить изменения:

1. **ОБЯЗАТЕЛЬНО**: Сделайте жесткую перезагрузку страницы в браузере:
   - Chrome/Safari: Cmd+Shift+R
   - Firefox: Cmd+Shift+R
   Это необходимо для загрузки нового JavaScript кода!

2. **Проверка трех фотографий StandartPlus**:
   - Откройте модальное окно редактирования "Главная"
   - Проверьте, что в галереях отображаются все фотографии
   - Не должно быть ошибки "undefined is not an object (evaluating 'image.src')"

3. **Проверка моментального обновления для галерей**:
   - Откройте модальное окно редактирования "Главная"
   - Измените/добавьте/удалите фото в галерее
   - Нажмите "Сохранить"
   - Изменения должны быть видны сразу, БЕЗ переоткрытия модального окна

4. **Проверка моментального обновления для процессов (BoxEditable)**:
   - Откройте модальное окно редактирования "Винодельня"
   - Нажмите "Добавить процесс"
   - Новый процесс должен появиться сразу, БЕЗ переоткрытия модального окна
   - Удалите процесс - он должен исчезнуть сразу
   - Измените название или фото процесса - изменения должны быть видны сразу

5. **Проверка CORS ошибок**:
   - Backend уже запущен на порту 5001
   - При перезагрузке админской страницы не должно быть ошибок "XMLHttpRequest cannot load..."
   - Если ошибка все еще есть, проверьте, что запущен только один экземпляр backend

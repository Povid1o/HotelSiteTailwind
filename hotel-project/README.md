# Frontend Винных Террас

React 18 + TypeScript + Tailwind, сборка Vite, тесты Vitest. Требуется Node.js 22.12 или новее.

```bash
npm ci --ignore-scripts
npm start
npm test
npm run build
npm run type-check
```

Сервер разработки слушает только `127.0.0.1:3000` и проксирует `/api` и backend-медиа на `127.0.0.1:5001`. Публичные настройки `REACT_APP_API_URL` и `REACT_APP_YM_ID` задаются окружением/.env. Только эти значения подставляются в bundle; секретов среди них быть не должно. Результат production-сборки — `build/`, source maps выключены.

В Docker приложение обслуживается nginx за Caddy. Строгая CSP применяется отдельно к `/login` и `/admin`; при переходе между публичной и административной частью загружается новый документ, чтобы исключить сторонние скрипты из админки.

Подробности проверки безопасности и оставшиеся ограничения: [аудит 11.11.2026](../docs/security-audit-2026-11-11/report.md). Общая проверка типов пока выявляет ошибки старых компонентов; успешная сборка Vite не означает, что type-check прошёл.
